# Domain

Contratos e regras compartilhados entre navegador e servidor ficam neste
diretorio. Entidades e regras do jogo serao adicionadas em issues proprias.

O teste `domain-infrastructure.test.ts` existe somente para comprovar a
infraestrutura de testes de regras puras em TypeScript. Ele nao antecipa os
contratos do jogo.
